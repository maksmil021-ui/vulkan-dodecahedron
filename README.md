# Лабораторная работа №1 по компьютерной графике

**Вариант10:** Правильный додекаэдр

## Описание
Отрисовка 3D-додекаэдра на C++ с использованием Vulkan API.
**Реализовано:**
- Генерация геометрии (20 вершин, 36 треугольников) через золотое сечение.
- Плоское затенение (Flat Shading) с диффузным освещением.
- Отрисовка закрашенных граней и черных ребер (Wireframe).
- Управление вращением и масштабом через ImGui.

## Сборка и запуск
**Требования:** Vulkan SDK, CMake (3.20+), компилятор C++20.
1. Клонировать репозиторий.
2. Сгенерировать проект через CMake (зависимости GLFW, GLM, ImGui, VMA скачаются автоматически).
3. Собрать проект и запустить `vulkan-starter-app.exe`.
