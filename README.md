# Лабораторная работа по компьютерной графике (Vulkan)

**Вариант 10:** Правильный додекаэдр

## Описание
Программа на C++ с использованием API Vulkan для отрисовки 3D-модели правильного додекаэдра в реальном времени.

**Реализовано (базовая часть + задания на оценку 4):**
- Генерация геометрии (20 вершин, 36 треугольников) на основе золотого сечения.
- Плоское затенение (Flat Shading) с диффузным освещением.
- Отрисовка закрашенных граней и черных ребер (Wireframe).
- Процедурная раскраска вершин с умножением на пользовательский цвет.
- Интерфейс на ImGui: переключение перспективной/ортографической проекции, изменение позиции, поворота, масштаба и цвета фигуры.
- Анимация движения по сложной траектории (с паузой, настройкой скорости и радиуса).

## Сборка и запуск
**Требования:** Vulkan SDK, CMake (3.20+), компилятор C++20.
1. Склонируйте репозиторий.
2. Сгенерируйте проект через CMake (зависимости GLFW, GLM, ImGui, VMA скачаются автоматически).
3. Соберите проект и запустите `vulkan-starter-app.exe`.
